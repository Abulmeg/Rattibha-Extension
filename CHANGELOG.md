# Changelog

## 0.11.0

- Raised the file-size limit for large PowerPoint conversions and improved slide-by-slide PDF export.
- Added progress feedback and reduced temporary image data kept in memory.

## 0.10.0

- Added direct PDF export for DOCX, PPTX and text files without the browser print dialog.

## 0.9.0

- Improved Moodle resource links, PDF previews and direct downloads for other file types.

## 0.8.0

- Added local file conversion, page-specific loading states and theme-aware branding.

## 0.7.0

- Improved navigation, tasks and the focus timer.

## 0.6.0

- Added messaging and refreshed the logo and interface.

Earlier versions focused on making course lists and materials easier to use.


## 0.12.0
- Added direct PDF shortcuts beside supported Office documents in course materials and the original Moodle interface.
- Simplified converter labels, course guidance, and extension popup.
- PDF conversion stays on-device; older binary PPT files require PPTX.

## 0.13.0
- Reads PowerPoint 97–2003 `.ppt` locally without asking students to convert to PPTX first.
- PDF shortcut now works for PPT, PPTX and DOCX in native and Rattibha course views.
- Legacy PPT PDF exports preserve slide text and sequence, not original artwork or animations.

## 0.14.0
- Browse Moodle folders and nested folder files in Rattibha, including optional ZIP download.
- Keep Moodle Page content and its links visible, instead of opening the first attached file automatically.
- Preview supported images, audio and video. Download other files and open interactive Moodle activities natively.
- Add folder filters, resource-type handling and PDF shortcuts within folders.
