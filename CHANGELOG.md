# Changelog

## 0.11.0

- Raised the file-size limit for large PowerPoint conversions and improved slide-by-slide PDF export.
- Added progress feedback and reduced temporary image data kept in memory.

## 0.10.0

- Added direct PDF export for DOCX, PPTX and text files without the browser print dialog.

## 0.9.0

- Improved Moodle resource links, PDF previews and direct downloads for other file types.

## 0.8.0

- Added local file conversion, page-specific loading states and theme-aware branding.

## 0.7.0

- Improved navigation, tasks and the focus timer.

## 0.6.0

- Added messaging and refreshed the logo and interface.

Earlier versions focused on making course lists and materials easier to use.
